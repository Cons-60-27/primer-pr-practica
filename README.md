# Primer PR Práctica

Repositorio de práctica para aprender a crear y fusionar mi primer Pull Request en GitHub.

## ¿Qué es un Pull Request?

Un Pull Request (PR) es una propuesta de cambios sobre un proyecto. En lugar de modificar
directamente la versión principal del código, se crea una rama con los cambios y se pide
que sean revisados antes de incorporarlos. Así se puede comentar, corregir y aprobar cada
mejora antes de que forme parte definitiva del proyecto.
